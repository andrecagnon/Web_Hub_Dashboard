**Dashboard Hub**, um portal corporativo centralizado para a gestão de indicadores operacionais. O projeto resolveu o problema de fragmentação de relatórios, unificando múltiplos dashboards do Power BI em uma única interface web de alta performance.

**Tecnologias e Práticas Adotadas:**

* Desenvolvimento do Frontend com apoio de Inteligência Artificial utilizando React.js, TypeScript e Vite, garantindo uma navegação rápida, responsiva e fortemente tipada.  
* Estilização de interface moderna focada em UX/UI utilizando Tailwind CSS.  
* Integração segura e dinâmica de relatórios empresariais via Power BI Embedded.  
* Arquitetura e provisionamento de infraestrutura em nuvem na AWS.  
* Automação de deploy (DevOps/CI-CD) utilizando AWS Amplify integrado ao GitHub, permitindo atualizações contínuas em produção com zero downtime.  
* Uso de redes de entrega de conteúdo (AWS CloudFront / CDN) para garantir o carregamento global ultrarrápido da aplicação estática.  

**Competências:** AWS Amplify · Amazon Web Services (AWS) · React.js · TypeScript · Integração Contínua (CI/CD) · Microsoft Power BI · Tailwind CSS · Git/GitHub · Inteligência Artificial.
